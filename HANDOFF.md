## Что собрано

Статический сайт, 4 страницы + документы, без бекенда:

```
./
├── index.html        01 Бюро      (hero «Бутик, а не конвейер», статемент, о бюро, принципы, процесс, цифры, CTA)
├── praktiki.html     02 Практики  (горизонтальная лента-обложка на десктопе, 5 практик подробно с «Что делаем», CTA)
├── komanda.html      03 Команда   (hero «Люди, а не логотип», статемент, групповое фото, 4 партнёра, принцип, CTA)
├── kontakty.html     04 Контакты  (заголовок, реквизиты, форма с чекбоксом согласия, карта, FAQ)
├── privacy.html      Политика ПДн (заглушка) + Правовая информация (#legal)
└── assets/
    ├── css/style.css         дизайн-система исходного макета + блоки сборки (30 КБ)
    ├── fonts/*.woff2         Vela + Cormorant ×2 — извлечены из base64, кэшируются между страницами
    ├── js/vendor/            GSAP 3.12.5, ScrollTrigger, Lenis, Splitting (как в макете)
    ├── js/main.js            хореография макета + честная обработка форм (mailto)
    └── img/                  21 файл: WebP 480/960/1600 + JPEG-фолбэк, favicon.svg
```

Сырой фотосет (не в git, см. `.gitignore`) лежит рядом в `raw-photos/` — до 2026-07-30 назывался `Assets/`; переименован, чтобы не конфликтовать по имени с `assets/` на файловых системах без учёта регистра (Windows).

Фото: из 4 ГБ фотосета конвертированы **выбранные ретушированные кадры** (чб-серия — она совпадает с монохромной палитрой макета): 4 портрета партнёров + групповой кадр. 12–15 МБ исходники → 17–278 КБ WebP. Исходники не тронуты (скрипт только читает; архив `2026-06-02 Адвокаты.zip` — резервная копия).

## Решения совета, применённые в сборке

1. **4 физические страницы** (контент-спека — контракт), общий CSS и шрифты .woff2 — кэш между страницами.
2. **Конвертированы только фото, которые использует сайт** — не все 436. Полный веб-архив — отдельная поставка по запросу (см. ниже).
3. **Дизайн переиспользован дословно** (clone-and-carve), новые блоки (процесс, цифры, CTA-ленты, FAQ, чекбокс) собраны из существующих токенов системы.
4. **Мёртвая форма устранена.** В макете обработчик имитировал успех («Отправлено ✓» без отправки). Теперь: форма формирует письмо в почтовом клиенте (mailto) — данные не уходят третьим сервисам, что чисто по 152-ФЗ; рядом всегда кликабельные телефон и почта. Подписка на дайджест — тоже mailto.
5. **AVIF пропущен** сознательно: WebP q82 + JPEG-фолбэк.

## Деплой (за пределами этой сессии — нужны доступы)

1. Любой статический хостинг: залить содержимое репозитория (без `raw-photos/`, `Content/`, `Desigan/`, `Skills/` — они не часть сайта) как корень.
2. Домен + DNS (учесть время распространения), TLS-сертификат.
3. Заголовки кэширования: `assets/fonts/*`, `assets/img/*`, `assets/js/vendor/*` — `cache-control: max-age=31536000, immutable`.
4. Проверить доступность встроенной карты OpenStreetMap из РФ; при проблемах заменить на статичное изображение карты (стиль уже готов — обёртка `.map-wrap`).
5. Подпись клиента (staging-URL) до публикации.
6. Аналитика/коллтрекинг — по желанию клиента (в сборке отсутствуют — ничего не трекается).

## Как править

- **Тексты** — прямо в HTML соответствующей страницы (разметка блоков подписана комментариями `===== BLOCK =====`).
- **Добавить практику** — скопировать `article.pcard` в ленте и блок `.pdetail` в деталях praktiki.html.
- **Заменить фото партнёра** — добавить кадр в `PICKS` скрипта конвертации, запустить, поправить `srcset` в komanda.html.
- **Шапка/подвал** — общие для всех страниц, при правке менять во всех 5 файлах (статика без шаблонизатора — сознательное решение для простоты хостинга).
